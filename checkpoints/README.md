# Released Checkpoints

This directory contains 24 CA-GAT-MAPPO `best_checkpoint.pt` files: 8 seeds for each of `static_clutter`, `pedestrian_dynamic`, and `mixed_complex`.

Each training block contains 100 training episodes and 20 validation records.

Checkpoint paths, SHA-256 digests, and protocol metadata are listed in [../dataset/provenance/released_checkpoints.csv](../dataset/provenance/released_checkpoints.csv).
