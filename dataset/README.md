# CA-GAT-MAPPO Dataset

CSV files are the authoritative machine-readable release. The XLSX file is a consolidated convenience copy.

## Overview

The main comparison contains 4 methods x 3 scenarios x 8 training seeds x 10 evaluation episodes = 960 episodes. Validation contains 4 methods x 3 scenarios x 8 training seeds x 20 validation points = 1920 records.

The dataset also includes ablation, classical-reference, safety-audit, safety-off, scalability, inference-benchmark, mechanism-trace, A* reference, runtime, and checkpoint-provenance data.
